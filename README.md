# Cofre do Cláudio

Aplicativo PWA leve e offline para guardar ideias, decisões, notas importantes e senhas organizadas por projeto.

## Primeira versão
- Offline após o primeiro carregamento
- Projetos separados
- Notas por categoria
- Favoritos e busca
- Cofre de senhas com senha-mestra
- Criptografia local AES-GCM
- Backup e restauração
- Instalação no celular como PWA

> As senhas ficam criptografadas no próprio aparelho. A senha-mestra não é salva.
